# ウルトラランナー動機タイプ診断

ウルトラトレイルへの動機を5軸で整理する、ブラウザだけで動作する簡易診断です。

- Performance
- Puzzle
- Community
- Adventure
- Narrative

## GitHub Pages で公開

1. GitHubで新しいリポジトリ（例: `ultra-runner-type`）を作成
2. このフォルダ内の `index.html` と `.nojekyll` をリポジトリのルートへアップロード
3. Repository の **Settings → Pages**
4. **Build and deployment → Source** で **Deploy from a branch**
5. Branch を **main**、folder を **/(root)** にして Save
6. 公開後、`https://<username>.github.io/ultra-runner-type/` でアクセス

## 注意
これは医学的・心理学的に検証された尺度ではなく、ウルトラランニングへの動機を整理するための自己評価モデルです。
